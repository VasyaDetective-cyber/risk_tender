## 🛠 Розв’язання

У цій лабораторній роботі треба було визначити найвигідніший проект для будівництва терміналу, враховуючи не тільки початковий кошторис компаній, але й ризики затримки строків. За умовами, кожен місяць відсутності терміналу приносить державі **40 000 доларів збитків**.

### 1. Підготовка даних
Спочатку я перевів усі вказані строки будівництва у місяці (наприклад, *3 роки = 36 місяців, 3 роки 2 місяці = 38 місяців* тощо), щоб звести все до єдиної системи вимірювання. Позначимо тривалість будівництва для кожної компанії як випадкові величини $X_A$, $X_B$, $X_C$.

### 2. Розрахунок середнього очікуваного часу
Щоб дізнатися реальні прогнозовані строки, я використав формулу математичного сподівання. Вона множить кожен можливий час ($x_i$) на його ймовірність ($p_i$):
`M(X) = x₁·p₁ + x₂·p₂ + x₃·p₃`

* **Для "A.Ink":** `M(X_A)` = 36·0,5 + 39·0,3 + 42·0,2 = **38,1 міс.**
* **Для "В.Ltd":** `M(X_B)` = 38·0,3 + 48·0,5 + 53·0,2 = **46 міс.**
* **Для АТ "С":** `M(X_C)` = 48·0,1 + 54·0,4 + 60·0,5 = **56,4 міс.**

### 3. Розрахунок загальної вартості зі збитками
Далі я порахував загальну вартість ($V$), додавши до кошторису збитки за кожен очікуваний місяць будівництва за формулою:
`V = Кошторис + M(X)·40000`

* **Для "A.Ink":** `V_A` = 3 400 000 + 38,1·40 000 = **4 924 000 $**
* **Для "В.Ltd":** `V_B` = 2 930 000 + 46·40 000 = **4 770 000 $**
* **Для АТ "С":** `V_C` = 2 500 000 + 56,4·40 000 = **4 756 000 $**

### 4. Оцінка ризику (наскільки можуть зірватися строки)
Щоб зрозуміти надійність компаній, я порахував дисперсію ($V(X)$) та середньоквадратичне відхилення ($\sigma$), яке показує ступінь ризику в місяцях:
`V(X) = (x₁ - M(X))²·p₁ + (x₂ - M(X))²·p₂ + (x₃ - M(X))²·p₃`  
`σ = √V(X)`

* **Для "A.Ink":** `σ_A` = √5,49 ≈ **2,34 міс.**
* **Для "В.Ltd":** `σ_B` = √31 ≈ **5,57 міс.**
* **Для АТ "С":** `σ_C` = √15,84 ≈ **3,98 міс.**

##  Висновок
Хоча американська компанія **"A.Ink"** будує найшвидше і має найменший ризик затримки строків (2,34 міс.), її проект у підсумку є найдорожчим (понад 4,9 млн дол.). Натомість українська фірма **АТ "С"**, незважаючи на найдовші прогнозовані строки, по фінансах виявляється найвигіднішою — її загальна вартість склала найменше (4 756 000 $). 

Ризик порушення строків у АТ "С" (3,98 міс.) знаходиться на прийнятному середньому рівні і є значно меншим, ніж у британської компанії. Тому, керуючись показниками загальної економічної ефективності та помірним ризиком, оптимально обрати проєкт **АТ "С" (Україна)**.
